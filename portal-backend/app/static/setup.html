Office 365 / Microsoft 365 now disables basic SMTP login (security default + MFA). To use SMTP you must enable one of these:
  • App password (easiest): turn off MFA requirement for SMTP or enable "App passwords" in your tenant, then paste the 16-char app password here. Requires SMTP AUTH to be enabled for the mailbox.
  • OAuth2 / Microsoft Graph (recommended for production): complete the Azure app registration (see docs/DEPLOYMENT.md §Azure), leave email blank here, and the portal sends reports via Graph instead of SMTP.
